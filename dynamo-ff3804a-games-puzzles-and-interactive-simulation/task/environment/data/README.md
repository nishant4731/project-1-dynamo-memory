Cairn calibration data. Infer profile constants from calibration.jsonl; solve each query in puzzles.json with the rules in the task prompt. Calibration row kinds are single-card terrain probes, same-row and same-column glyph pulse drift probes, non-dot terrain pulse probes, ordered adjacent-pair probes, and anchor probes next to `#`. Pair probes include both lower-previous-rank and higher-previous-rank examples so the documented link multiplier `min(previous_rank,current_rank)` is identifiable. `anchor_bonus` is a single integer added when a placement cell is orthogonally adjacent to `#`.
