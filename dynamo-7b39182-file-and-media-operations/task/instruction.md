Create an executable Python 3 program at `/app/repair_reels.py` that takes one workspace path, repairs it in place, and leaves only `timeline.csv` and `repair_report.json`. After both outputs are written, delete consumed evidence: `clips.tsv`, `takes.tsv`, `lanes.csv`, `aliases.tsv`, `budgets.csv`, `anchors/`, and `events/`.

Workspace files: `clips.tsv` (`clip_id	fps_num	fps_den	total_frames`); `takes.tsv` (`take_id	edit_fps_num	edit_fps_den	pack_granularity	splice_pad`); `lanes.csv` (`scene,lane`); `aliases.tsv` (`alias	scene`); `budgets.csv` (`lane,max_duration_frames`); `anchors/<clip_id>.csv` (`logged_frame,actual_frame,status,operator_note_offset`); `events/*.jsonl`.

Use only anchor rows with status `verified` or `superseded`; ignore `operator_note_offset`. For a segment, pick the usable anchor on that clip with greatest `logged_frame` ≤ `start_logged`; if none, use the clip's smallest `logged_frame`. Ties at that logged frame: `verified` before `superseded`, then greatest `actual_frame`. No usable anchor → discard and count under `bounds_rejected`. Offset is `actual_frame - logged_frame`.

Each event JSON has `event_id`, `scene`, `slot`, `rev`, `kind`, `clip_id`, `start_logged`, `length`, `head_trim`, `tail_trim`, `speed_num`, `speed_den`, `authority`, `take_id`, `tag`. `kind` is `segment` or `void` (void has empty `clip_id` and zero span fields except speed `1/1`). Digest-valid iff `tag` equals the first 16 lowercase hex chars of SHA-256 of:

`event_id|scene|slot|rev|kind|clip_id|start_logged|length|head_trim|tail_trim|speed_num|speed_den|authority|take_id`

Read `events/*.jsonl` in lexicographic path order. Drop digest-invalid events. Among digest-valid duplicates of an `event_id`, keep the lexicographically greatest file, then the later line. Drop events whose `take_id` is absent from `takes.tsv`. Then rewrite `scene`: if it appears as `alias` in `aliases.tsv`, replace it with that row's `scene` (count each changed event). For segments, `src_in = start_logged + offset + head_trim` and exclusive `src_out = start_logged + offset + length - tail_trim`. Drop a segment (and count it under `bounds_rejected`) when any of these hold: clip unknown; no usable anchor on that clip; `speed_num` or `speed_den` not positive; `src_in < 0`; `src_out <= src_in`; `src_out > total_frames`. Drop any event whose `kind` is neither `segment` nor `void` the same way (also `bounds_rejected`). Voids skip clip/anchor/bounds checks.

Group by `(scene, slot)` using the rewritten scene. Canonical event: highest `rev`, then authority `operator` > `ingest` > `proxy`, then smallest `event_id`. Void canonical → no row. Segment whose rewritten scene lacks a `lanes.csv` row → drop for emission. Remaining segment canonicals are emit candidates.

Same-clip overlap: among emit candidates sharing `clip_id`, if `[src_in, src_out)` ranges overlap, keep the higher-priority one (same priority as canonical) and drop the other; repeat until no overlaps remain.

Base `duration_frames` uses exact integer ceil of source span after clip fps and event speed, with the take's `edit_fps_num/edit_fps_den`, then ceil-snaps up to a multiple of `pack_granularity`. Source span is `src_out - src_in`; speed `2/1` is twice normal, `1/2` half. Sort survivors by `lane`, rewritten `scene`, `slot`, `event_id`. Within each lane, walk that order: add the current row's take `splice_pad` to its duration only when the previous surviving row shares both the same `lane` and the same `clip_id`; consecutive same-lane rows with different `clip_id` get no pad. Then enforce `budgets.csv`: if a lane has a max and the lane's duration sum exceeds it, repeatedly evict the lowest-priority row in that lane (lowest `rev`, then lowest authority rank, then greatest `event_id`) and recompute that lane's splice pads from scratch on the remaining sorted rows until the sum fits. Lanes absent from `budgets.csv` are unlimited.

Write `timeline.csv` with header `scene,slot,event_id,clip_id,edit_in,edit_out,src_in,src_out,duration_frames` in the final sort order. `edit_in` accumulates `duration_frames` within each lane; `edit_out = edit_in + duration_frames`. Emit the rewritten scene name.

`repair_report.json` keys: `raw_events`, `digest_rejected`, `replayed_events`, `take_rejected`, `alias_rewrites`, `bounds_rejected`, `canonical_groups`, `void_selected`, `lane_missing`, `superseded_records`, `overlap_evicted`, `budget_evicted`, `timeline_rows`, `total_duration_frames`, `per_scene_duration`, `per_lane_duration`. Counts are: loaded events; bad tags; digest-valid replay losers; unknown takes; alias rewrites; events dropped by the segment/kind checks listed above (not take rejects, not void skips, not later overlap/budget drops); `(scene,slot)` groups after those filters; void canonicals; laneless canonical segments; non-canonical group members; overlap drops; budget drops; emitted rows; duration sum; per rewritten scene sums; per lane sums.
