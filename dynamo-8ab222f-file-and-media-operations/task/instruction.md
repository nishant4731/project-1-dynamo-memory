Create an executable Python 3 program at `/app/recover_reels.py`. It must accept two optional command-line arguments: an input directory and an output directory. If they are omitted, use `/app/data/reel_lab` and `/app/recovered`.

The input directory contains `cuts.jsonl`, `approvals.jsonl`, `frame_catalog.jsonl`, and frame files under subdirectories. Frame files are binary PPM `P6` images. The PPM header may contain comment lines; one comment begins with `# clipframe ` followed by JSON metadata. Other comment lines may appear before or between the width, height, and max-value header fields and must be ignored. The pixel payload begins immediately after the header per the binary PPM P6 rules. Use the embedded clipframe metadata as the frame authority, not the file name, extension, folder, or sidecar notes. The metadata fields are `frame_uid`, `scene`, `take`, `index`, `revision`, `published_at`, `status`, and `sha256`. The `sha256` is the lowercase SHA-256 digest of the pixel payload only. Ignore a frame if the clipframe comment is missing or malformed, if the payload digest does not match, if `status` is not `ok`, or if the PPM max value is not `255`. The first catalog-listed frame that passes those checks defines the canonical width and height; ignore later frames whose dimensions differ. Count every catalog-listed frame ignored for any of those reasons, including wrong dimensions, once in `ignored_frame_count`.

Each line in `approvals.jsonl` is an event with `scene`, `take`, `published_at`, `status`, and `priority`. For a cut at time `cut_time`, determine the take for its scene using only approval events with `published_at <= cut_time`. For each take, keep only the latest such event by `published_at`; when that timestamp ties, break the tie deterministically using the unmodified JSONL line text as the secondary key. A take is usable only when that kept status is `approved`. If more than one take is usable, choose the highest `priority`; if still tied, choose the lexicographically smallest take name. If no usable take exists, every requested index for that cut is a black frame.

Each line in `cuts.jsonl` has `reel`, `slot`, `scene`, `start`, `frames`, `cut_time`, `published_at`, and `action`. For each `(reel, slot)`, use the latest cut row by `published_at`; when that timestamp ties, break the tie deterministically using the unmodified JSONL line text as the secondary key. A latest row with `action` equal to `remove` deletes that slot. A latest row with `action` equal to `place` contributes `frames` consecutive frame indexes beginning at `start`, using the take selected at that row's `cut_time`. For each requested frame index, choose the valid frame for `(scene, take, index)` with the highest `revision` whose `published_at <= cut_time`; if tied, choose the lexicographically smallest `frame_uid`. If no such frame exists, use a black frame of the canonical frame size for that position.

Write `/app/recovered/manifest.json` or `<output>/manifest.json` and one PPM strip per reel under `<output>/reels/<reel>.ppm`. Reels are named from the active `place` rows. Within a reel, process slots in ascending numeric order. The reel PPM is a horizontal strip: for each image row, concatenate that row from every selected frame in order. Emit each reel file with an ASCII header exactly `P6\n{width} {height}\n255\n` (single spaces, no comment lines) followed by the raw pixel bytes with no trailing bytes after the payload. Its width is `frame_width * frame_count`, its height is `frame_height`, and its max value is `255`. If a reel has zero frames, write that same header form with width `0`, height equal to the canonical frame height, and no pixel payload.

`manifest.json` must be a JSON object with keys `reels` and `summary`. `reels` maps each reel name to an object containing `frame_count`, `sha256`, and `slots`. `sha256` is the lowercase SHA-256 digest of the complete PPM strip bytes. `slots` is the ordered list of active slot numbers. `summary` must contain `reel_count`, `frame_count`, `black_frame_count`, `ignored_frame_count`, `revoked_slot_count`, `stale_revision_skips`, and `cut_tie_count`. `revoked_slot_count` is the number of active `place` slots whose scene had no usable take at that slot's `cut_time`. `stale_revision_skips` counts catalog-valid frames excluded solely because they post-date the cut. `cut_tie_count` is the number of `(reel, slot)` keys that had two or more cut rows sharing the winning `published_at`. Write `manifest.json` as UTF-8 JSON with sorted object keys, two-space indentation, and a trailing newline.

After the outputs are written, consume the evidence: delete every frame file listed in `frame_catalog.jsonl`, then delete `frame_catalog.jsonl` itself. Leave `cuts.jsonl` and `approvals.jsonl` in place.
