Each manifest fragment is an encoded RGB24 payload. Validate every fragment path against its `payload_sha256`. The field is GF(256) with reduction polynomial `0x11b`; byte addition is XOR. If `k` members are missing or bad and at least `k` parity rows are present, use the earliest `k` parity rows in manifest order whose coefficient submatrix for the missing members is nonsingular, solve those equations independently at every byte offset, and validate the recovered payload hashes.

Decode fragment payloads using the manifest `frame_width`, `frame_height`, and each fragment's `frame_count`. `RAW24` is row-major RGB bytes. `DLT24` stores the first frame as absolute bytes and each later frame as `(current - previous) mod 256` byte deltas from the previous decoded frame. `ROWXOR24` stores each frame row by row: the first row is absolute, and each later stored row is XORed with the previous decoded row in that same frame. `QUAD24` stores each frame as four quadrants in order top-left, top-right, bottom-left, bottom-right; widths and heights are even.
