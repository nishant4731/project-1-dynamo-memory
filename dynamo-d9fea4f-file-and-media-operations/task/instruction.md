Create a reusable Python 3 command-line program at `/app/restore_sheet.py`. It must accept exactly two positional arguments:

`python3 /app/restore_sheet.py <workspace_dir> <output_dir>`

The program repairs a crashed sticker-sheet export. A workspace contains `workspace.json`, `placements.csv`, `assets/*.png`, optional `masks/*.png`, and optional calibration files under `calibration/`. The shipped sample workspace is `/app/workspaces/sample`.

`workspace.json` defines `tile_size`, `rows`, `columns`, `cutoff_utc`, and `layers`. Canvas size is `columns * tile_size` by `rows * tile_size`, transparent RGBA. Each layer has `layer_id`, integer `z`, and boolean `visible`. Ignore any print-shop offset hints such as a `shop_registration` object in `workspace.json`; registration offsets come only from calibration probes.

`placements.csv` has columns `event_id,piece_id,layer_id,row,col,dx,dy,asset,mask,opacity,transform,effective_at,revision,op`. The file may start with a UTF-8 BOM. Skip blank lines and lines whose first non-whitespace character is `#` (count each skipped line in `skipped_lines`); remaining data rows may be out of order. Ignore events with `effective_at` later than `cutoff_utc`. For each `piece_id`, select the current event by latest `effective_at`; break ties by higher integer `revision`; break remaining ties by lexicographically larger `event_id`. Count every non-selected event that was not future-ignored as a superseded event. If the current event has `op` equal to `delete`, the piece is not rendered. If its layer is missing or not visible, it is not rendered. Otherwise render it.

If the calibration directory contains an index CSV file, derive a pixel registration offset for each listed layer. It has columns `probe,layer_id,asset,mask,opacity,transform,origin_x,origin_y,underlay`. A probe PNG starts from a transparent canvas the same size as the final sheet. If `underlay` is non-empty, first composite `assets/<underlay>` once at `(origin_x, origin_y)` with opacity 100, transform `none`, and no mask. Then composite the listed asset after the listed transform, opacity, and mask once at `(origin_x + offset_x, origin_y + offset_y)`. Search integer offsets in `-16..16` inclusive and intersect the pairs that reproduce every probe row for that layer exactly; an individual probe row may match more than one pair. Use offset `(0,0)` for layers not listed.

Render current pieces in ascending `(layer z, effective_at, piece_id)` order. Use non-premultiplied straight-alpha source-over RGBA compositing with round-half-up integer division `round_div(n, d) = (n + d // 2) // d` (and `0` when `d <= 0`) at every division step; do not premultiply RGB by alpha and do not use library compositors that floor intermediate products. Derive and validate your compositing pipeline against the shipped sample pixels. Place each asset at `(col * tile_size + dx + offset_x, row * tile_size + dy + offset_y)` using that layer's calibrated offset; clip outside the canvas. `transform` is one of `none`, `rot90`, `rot180`, `rot270`, `flip_x`, or `flip_y`; rotations are clockwise and applied before opacity and mask. `opacity` is an integer percent 0–100; attenuate alpha with `(alpha * opacity + 50) // 100`. If `mask` is non-empty, load `masks/<mask>` as grayscale after transform and opacity, then attenuate alpha with `(alpha * mask + 127) // 255`. Masks are not transformed. RGB channels are not premultiplied. Pixel grading compares RGBA values, not PNG encoder bytes.

Write exactly two outputs in `<output_dir>` as regular files (not symlinks):

`sheet.png`: the repaired RGBA PNG.

`ledger.json`: UTF-8 JSON with keys `canvas`, `counts`, `layer_offsets`, `asset_usage`, `layer_usage`, `cell_stack`, and `image_sha256`. `canvas` is `{"width": W, "height": H}`. `counts` has integer keys `records_read`, `skipped_lines`, `future_ignored`, `superseded_events`, `current_pieces`, `deleted_pieces`, `invisible_layer_ignored`, `rendered_pieces`, `masked_renders`, `edge_clipped`, and `calibration_probes`. `records_read` counts non-skipped placement data rows (not the header). `superseded_events` counts placement rows that were not future-ignored and were not selected as the current event for their `piece_id`. `current_pieces` counts unique `piece_id`s with a selected current event after cutoff filtering and before any `op` or layer-visibility filtering; `deleted_pieces` and `invisible_layer_ignored` are subcategories of `current_pieces`, so `current_pieces = rendered_pieces + deleted_pieces + invisible_layer_ignored`. `masked_renders` counts rendered pieces with non-empty `mask`. `edge_clipped` counts rendered pieces whose transformed asset rectangle would extend outside the canvas before clipping. `calibration_probes` counts calibration index rows, not distinct layers; if there is no calibration index file, it is `0` and `layer_offsets` is `{}`. `layer_offsets` maps each calibrated layer id to `[offset_x, offset_y]`, sorted by layer id; omit unlisted layers. `asset_usage` and `layer_usage` map rendered asset filenames and layer ids to counts, each sorted by key. `cell_stack` maps `"row,col"` to the rendered `piece_id` list using each piece's CSV `row` and `col` exactly (not pixel coordinates or offsets), preserving render order; omit empty cells. `image_sha256` is the lowercase SHA-256 hex digest of the exact bytes of `sheet.png`.

Create `<output_dir>` if needed. After writing both outputs, delete the workspace `calibration/` directory if it exists. Do not otherwise modify the workspace.
