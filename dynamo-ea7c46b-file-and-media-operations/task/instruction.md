Create executable Python 3 program `/app/recover_design.py`. It accepts one design-pack directory argument. Running `python3 /app/recover_design.py /app/design_pack` must write `/app/design_pack/recovered.ppm` and `/app/design_pack/manifest.json`; the verifier runs the same program on other packs. After both files are written, recursively delete only that pack's `fragments` and `masks` directories. Rerunning on the consumed pack without restoring them must fail.

A pack has `palette.tsv`, `layout.json`, `cell_events.tsv`, `fragments/*.pxf`, optional `masks/<stem>.mask`, optional `channel_bindings.tsv`, optional `repairs.tsv`, and optional `fragments/<stem>.chk`. `palette.tsv` header is `name revision state priority r g b`: for each name choose among active rows by largest numeric revision, then largest numeric priority, then earliest active file row. `layout.json` has `canvas.width`, `canvas.height`, `canvas.background`, `grid.tile`, optional integer `layer_offset` default `0`, optional integer `origin.x/y` default `0`, and cells with `id`, `fragment`, `grid_x`, `grid_y`, `layer`, `transform`, `tone`, `opacity_permille`, `status`. `cell_events.tsv` header is `cell_id seq op field value`; apply rows by ascending numeric `seq`, ignoring unknown `cell_id`. `set` replaces a field. `add`/`mul` apply integer addition/product only on `grid_x`, `grid_y`, `layer`, `opacity_permille`; their values are whole integers. After events parse those four fields as integers, add `layer_offset` to `layer`, clamp `opacity_permille` into `0..1000`, and render only final active cells whose fragment integrity passes.

PXF text format: line 1 `PXF1`; line 2 `size=<width>x<height>`; line 3 `anchor=<x>,<y>`; line 4 `pixels=` plus `|`-separated rows of space-separated `color:count` runs. `.` is transparent, and every decoded row must match the declared width. A mask has one `1`/`0` row per fragment row; missing mask means all non-`.` pixels are paintable. A `.chk`, when present, must contain one non-empty line `sha256=<hex>`, the lowercase SHA-256 of the original `.pxf` bytes before repairs; a missing `sha256=` prefix or digest mismatch means the active cell is corrupt, unpainted, and listed in `corrupt_cells`. Missing `.chk` means trusted.

If `repairs.tsv` exists, its header is `seq fragment kind x y value`. Sort repair rows by numeric `seq`, then file row. Apply only rows whose `fragment` equals the fragment stem of at least one final active non-corrupt cell, whose `kind` is `pixel` or `mask`, and whose zero-based `x,y` are inside the original decoded source bounds. A `pixel` row sets that source pixel to `value`, which may be `.`, a palette name, or a `$` channel token. A `mask` row sets that source mask bit to `1` or `0`; if the mask file is missing, start from the implicit all-paintable mask before applying repairs. Repairs happen after checksum validation and before any transform, so all cells using that trusted fragment see the same repaired source grid and mask.

If `channel_bindings.tsv` exists, its header is `fragment channel cell_id layer_mod layer_rem transform tone color`. PXF colors starting `$` are local channels; other colors are palette names. Resolve `$x` per final cell using rows whose `fragment` equals the fragment stem, `channel` equals `x`, and constraints match. `*` is wildcard. Otherwise `cell_id`, `transform`, `tone` must equal the final cell fields; `layer_mod/layer_rem` match when both are not `*` and `final_layer % int(layer_mod) == int(layer_rem)`. Choose the matching row with most non-wildcard constraints, counting the layer pair as one; ties choose the later file row. Look up the chosen `color` in the selected palette.

Transform pixels and mask together before placement. Row 0 is top, column 0 left, and anchor is `(column,row)`. Transforms: `none`; `flip_x` mirrors left/right; `flip_y` mirrors top/bottom; `rot90` is 90 degrees clockwise; `rot180`; `rot270` is 270 degrees clockwise. Rotations swap width/height as appropriate. Remap the anchor with the same content-preserving map so it still names the same fragment pixel afterward.

Place active non-corrupt cells at `left = origin.x + grid_x * tile - anchor_x`, `top = origin.y + grid_y * tile - anchor_y`. Fill with the background color. Paint cells by ascending `(layer, grid_y, grid_x, id)`. Tones: `normal`; `multiply_80` uses `int(channel * 80 / 100)`; `screen_25` adds `ceil((255-channel)*25/100)`. Blend with round-half-up permille compositing on `0..1000` opacity. Clip off-canvas pixels. `overpaint_count` counts on-canvas blends whose destination pixel was already blended by an earlier painted cell; background alone does not count.

`recovered.ppm` is binary PPM P6: header exactly `P6\n<width> <height>\n255\n`, then row-major RGB bytes. `manifest.json` is UTF-8 JSON with sorted keys, two-space indent, and one trailing newline. It contains exactly: `canvas` with `width`/`height`; `image_sha256` of complete PPM bytes; `painted_cells` in paint order, one entry per active non-corrupt cell with `id`, `fragment`, `left`, `top`, `layer`, `painted_pixels`, `clipped_pixels`; `skipped_cells` sorted final non-active ids; `corrupt_cells` sorted active corrupt ids; `events_applied` count of event rows with known `cell_id`; `repair_rows_applied` count of repair rows actually applied; `repaired_fragments` sorted stems with at least one applied repair; `mask_culled_pixels` total post-transform nontransparent pixels rejected by mask across painted cells; `overpaint_count`; `consumed_evidence` true; `palette_revisions` mapping every resolved palette color in a mask-accepted nontransparent painted-cell pixel before clipping, plus background, to selected revision. `painted_pixels` counts mask-accepted nontransparent pixels blended onto canvas even when opacity is `0`; `clipped_pixels` counts those landing outside.
