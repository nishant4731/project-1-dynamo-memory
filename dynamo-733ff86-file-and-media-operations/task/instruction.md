Create executable `/app/recover_reel.py` taking exactly `<data_dir> <output_dir>`. Running `python3 /app/recover_reel.py <data_dir> <output_dir>` recovers any matching workspace and writes `<output_dir>/reel.gray` and `<output_dir>/reel_summary.json`. After both succeed, delete from `<data_dir>`: `fragments.csv`, `parity_groups.csv`, `telemetry.csv`, `auto_calibration.csv`, `codec_calibration.csv`, `capture_anchors.csv`, `reel_manifest.json`. Also run once on `/app/data` → `/app/recovered`.

Data files: `reel_manifest.json`, `telemetry.csv`, `parity_groups.csv`, `fragments.csv`, `auto_calibration.csv`, `codec_calibration.csv`, `capture_anchors.csv`.

`reel.gray`: raw 8-bit grayscale frames in order; each frame row-major, no header. `reel_summary.json` UTF-8 JSON with exactly: `width`, `height`, `frame_count`, `fps`, `global_sha256`, `scene_cut_frames`, `brightest_frame`, `dropped_fragment_count`, `valid_fragment_count`, `phase_boundary_data_fragment_count`, `selected_data_tile_count`, `selected_auto_data_tile_count`, `selected_scramble_data_tile_count`, `selected_auto_parity_count`, `selected_scramble_parity_count`, `selected_revision_checksum`, `fixed_point_round_recoveries`, `recovered_tile_count`, `temporal_delta_tile_count`, `clock_adjusted_fragment_count`, `superseded_anchor_usage_count`, `superseded_valid_fragment_count`, `parity_snapshot_blocked_count`.

Read width/height/frame_count/fps/tile_size/scene_cut_threshold from the manifest. Square tiles. `fragments.csv`: `capture_ms,frame,tile_row,tile_col,kind,group_id,revision,codec,payload_hex,crc16`.

Decode `payload_hex`; `crc16` must equal low 16 bits of CRC-32 over those bytes as four lowercase hex digits. Mismatches → `dropped_fragment_count`; matches → `valid_fragment_count`.

`capture_anchors.csv`: `band_start_ms,band_end_ms,logged_capture_ms,corrected_capture_ms,status,operator_skew_ms`. Use only `verified`/`superseded`; ignore `operator_skew_ms`. For each CRC-valid fragment, take anchors whose inclusive band contains `capture_ms` and `logged_capture_ms <= capture_ms`. If none, offset 0; else greatest `logged_capture_ms`, ties prefer `verified` over `superseded`, then greatest `corrected_capture_ms`. Offset = `corrected_capture_ms - logged_capture_ms`. Effective time = `capture_ms + offset`. Nonzero offsets → `clock_adjusted_fragment_count`. Chosen `superseded` anchors → `superseded_anchor_usage_count`.

For `kind=data`, sensor `tile_row`/`tile_col`. Telemetry: greatest `effective_capture_ms <=` fragment effective time (inclusive). `forward`: display col = sensor col. `mirror_x`: `tiles_per_row - 1 - sensor_col`. Display row = `tile_row`. CRC-valid data with effective time exactly on a telemetry boundary → `phase_boundary_data_fragment_count`.

Codecs: `raw` row-major; `xor55` XOR `0x55`; `revrows` reverse each tile row; `zigzag` diagonal zig-zag from top-left with alternating diagonal direction — recover the exact traversal from `codec_calibration.csv` (payload vs decoded SHA-256); `scramble` — recover the byte permutation from the scramble calibration row's `payload_hex` ↔ row-major `decoded_hex`; `auto` selects among `raw|xor55|revrows|zigzag` using the unique affine combination of `(frame, display_tile_row, display_tile_col, revision)` modulo 4 that fits every `auto_calibration.csv` row (small non-negative integer coefficients); apply that mined selector to every `auto` fragment; `delta_prev` XORs payload with prior-frame canonical tile at same display coords (frames > 0 only; never via `auto`).

Duplicate valid data for same frame+display tile: highest `revision`, then highest CSV `capture_ms` (not adjusted). Deferred `delta_prev` waits for prior-frame tile, then same rule. `selected_data_tile_count` = final canonical data tiles (not parity). `selected_auto_data_tile_count` / `selected_scramble_data_tile_count` / `temporal_delta_tile_count` = finals whose original codec was `auto` / `scramble` / `delta_prev`. `selected_revision_checksum` = sum `(frame+1)*(display_tile_row+1)*(display_tile_col+1)*(revision+1)` over final canonical data only. `superseded_valid_fragment_count` = CRC-valid fragments that lost revision/`capture_ms` selection for their key before fixed-point: data keys `(frame,display_row,display_col)` within the immediate-data map or the deferred-delta map separately; parity keys `(frame,group_id)`.

`parity_groups.csv`: `group_id` → `row:col` members (`;`-separated). Overlapping, unsorted. `kind=parity`: ignore tile coords; select by `(frame,group_id)` same tie-break. Parity `auto` uses parity frame, first member's display row/col, parity revision. `selected_auto_parity_count` / `selected_scramble_parity_count` as named.

Parity payload = XOR of four canonical group tiles. Fixed-point: before each parity scan, apply every currently decodable `delta_prev`. Snapshot all positions with any chosen data fragment (including still-deferred deltas); snapshot positions are parity-ineligible that scan. Scan groups in file order; when exactly one non-snapshot member lacks a tile, XOR parity with the other three. Same-scan fills may help later groups; newly unlocked deltas wait for the next round. `recovered_tile_count` = parity fills. `fixed_point_round_recoveries` = per-scan parity-fill counts for rounds that filled ≥1 (no delta fills, no zeros). `parity_snapshot_blocked_count` = across rounds, observations where exactly one member lacked a tile but that member was snapshot-ineligible.

Assemble `reel.gray`. `global_sha256` = SHA-256 of raw reel. `scene_cut_frames` = sorted `i` where mean abs diff of frames `i-1` and `i` > threshold. `brightest_frame` = highest mean pixel frame; ties → smaller index.
