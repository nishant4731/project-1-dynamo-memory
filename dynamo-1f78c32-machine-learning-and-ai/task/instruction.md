Create a Python program at `/app/recover_atlas.py` and use it to write `/app/atlas_answer.json` for the visible corpus in `/app/atlas`. The program must also work as `python3 /app/recover_atlas.py <atlas_dir> <output_json>` on another atlas directory with the same schema.

Each atlas has `manifest.json`, `model_cards.json`, `calibration.jsonl`, `events.jsonl`, and `probes.json`. Arithmetic is over the prime field `1000003`. Store vectors internally as residues `0..1000002`; when writing vectors or comparing calibration targets, convert each coordinate to signed form by subtracting `1000003` only when the residue is greater than `500001`.

Process event records in increasing `(tick, seq, record_id)`. A record is valid only when its `digest` equals the first 20 hex characters of SHA-256 over the same JSON object without `digest`, serialized with sorted keys and compact separators `(",", ":")`. Count invalid digests as `bad_digest`; otherwise ignore records with `status` equal to `retracted` and count them as `retracted_records`.

`seed` records set a node's canonical latent vector. Use the first valid non-retracted seed for a node in event order. `edge` records normally describe `dst = src + delta`. If an edge has `pivot` and nonzero integer `mix`, it instead describes `dst = src + mix*pivot + delta`; use any two known endpoint vectors among `src`, `pivot`, and `dst` to recover the third. Some `encoded_delta` entries may be `null`; repair each null from valid non-retracted `fill` records whose `(target, index)` names that edge record and coordinate. If several fills compete, choose highest `priority`, then lowest `(tick, seq, record_id)`. Count chosen fills as `filled_coordinates`; count valid fills that are not chosen as `ignored_fills`. An edge can be partly repaired and still have another null; count the chosen fills, then count that edge as `unfilled_edges` and not usable.

To decode a complete edge, infer the adapter policy for that `model` from `calibration.jsonl`. Each calibration row gives `model`, `tick`, `encoded_delta`, and the signed `true_delta` produced by that model card. For each encoded coordinate, the card's `bias`, `drift`, and `gain` fields participate in one affine lane over the field; calibration evidence determines the routed true coordinate, sign orientation, drift direction using the row's `tick`, and whether `gain` is applied or inverted. Choose the single policy per model that matches every calibration row exactly, then apply it to event edges for that model.

Recover nodes by repeatedly scanning usable edges in event order until a full pass adds no nodes; do not prioritize any `lane` value over another. For normal edges, if `src` is known and `dst` is unknown set `dst = src + delta`, and if `dst` is known and `src` is unknown set `src = dst - delta`. For mixer edges, use the field inverse of `mix` when solving for `pivot`. Never overwrite an already recovered node vector. Count edges that first assign a node as `used_edges`. After convergence, count usable normal edges with an unknown endpoint, or mixer edges with fewer than all three endpoint vectors known, as `deferred_edges`; count usable edges whose known endpoints violate their relation as `conflict_edges`.

`/app/atlas_answer.json` must be a single valid JSON object matching this schema: `schema` is `"atlas-recovery-v1"`, `dataset_id` from the manifest, `field_modulus` as the integer `1000003`, `probes` as one entry per id in `probes.json` order, and `report`. Each probe entry has `id`, `vector` as JSON integers in signed coordinate form, and `token`. The token for a residue vector uses its signed coordinates `s`: `mix = sum((i+3)*s[i]) mod 997`, `bits` has bit `i` set when `s[i] < 0`, `norm = (sum(abs(s[i])) // 113) mod 251`, formatted as `B{mix:03d}-{bits:02x}-{norm:03d}`.

The `report` must contain exactly these JSON-integer fields: `total_records` is the number of event rows after event ordering; `bad_digest` is invalid-digest rows; `retracted_records` is valid rows whose `status` is `retracted`; `valid_seeds` is first valid non-retracted seed rows that initialize a node; `valid_edges` and `valid_fills` count valid non-retracted rows of those kinds; `filled_coordinates` counts null edge coordinates repaired by chosen fills; `ignored_fills` counts valid fills not chosen; `unfilled_edges` counts edge records still missing at least one coordinate; `used_edges` counts usable edges that first assign a node; `deferred_edges` counts usable edges with an unknown endpoint after convergence; `conflict_edges` counts usable edges whose two known endpoints disagree; `resolved_nodes` counts recovered nodes; and `probes_written` is the probe entry count.
