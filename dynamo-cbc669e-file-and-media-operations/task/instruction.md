Recover canonical OrbitCam grayscale frames from `/app/archive/records.jsonl`. Write `/app/output/recovered_timeline.json` and `/app/output/contact_sheet.pgm`.

Read cutoff from `/app/archive/cutoff_ms.txt`. All JSONL rows are unordered. For any ledger row, use only `status == "active"` and `published_ms <= cutoff`; when several rows cover the same item, choose the greatest tuple named below. For records, choose each `(clip_id, frame_no)` by greatest `(published_ms, revision, record_id)`. The record `timestamp_ms` is preliminary. Canonical timestamps come from `/app/archive/clock_segments.jsonl`: choose the covering inclusive `[frame_start, frame_end]` row by greatest `(published_ms, revision, segment_id)`, then compute `origin_ms + (frame_no - frame_start) * period_ms`. Decode chosen records by clip in increasing `frame_no`; apply repair, calibration, stabilizer, then echo. Frames are 10x8 bytes after repair.

Codecs for row-major 8-bit `payload_b64`: `raw8` is raw bytes; `rle8` is `(count,value)` pairs; `delta8` is `(previous_repaired_byte + delta_byte) % 256` and is invalid for frame 0; `mirxor8` means undo XOR with `xor_key`, then reverse each row.

Repair rows in `/app/archive/repair_stripes.jsonl` identify unknown zero-based row-major pixels over modulo `modulus` (257 here). `coefficients` align with `erasure_indices` and enforce `sum(coefficients[i] * pixel[erasure_indices[i]]) % modulus == target`. Use `/app/archive/repair_policy.json`: for matching `(clip_id, frame_no)`, keep only local candidates whose listed `erasure_index` value appears in that entry's `values`; that index may be any listed erasure, not just the final degree of freedom. Frames without a policy entry keep every locally valid candidate. For each global candidate set satisfying all active repair rows and byte range `0..255`, compute `global_residue = sum(coefficient * named_pixel) % modulus` over policy `residue_terms`; repeated residue rows are separate terms and each occurrence contributes. Keep only `target_residue`. Choose the set minimizing final total `motion_from_previous` after repair, later `delta8`, calibration, stabilizer, and echo. Ties use lexicographically smallest repaired pixel sequence ordered by `(clip_id, frame_no, erasure_index)`. Repaired pre-calibration frames are later `delta8` predecessors.

Calibration from `/app/archive/calibration_segments.jsonl`: choose covering row by greatest `(published_ms, revision, calibration_id)`. For calibrated pixel `(x,y)`, read `source = repaired[y,(x-row_roll) mod 10]`; `mask = (xor_mask + column_phase*x + y) mod 256`; output `((source xor mask) + add_mod) mod 256`. Calibration feeds stabilization, not `delta8`.

Stabilizer from `/app/archive/stabilizer_segments.jsonl`: choose covering row by greatest `(published_ms, revision, stabilizer_id)`. Process each clip forward with `carry = 0` before frame 0. For each calibrated frame, `sample_sum = sum(calibrated[i] for i = sample_phase, sample_phase + sample_stride, ... < 80)` and `seed = (carry + seed_bias + sample_sum) mod 256`. Pixel `(x,y)` becomes `calibrated[y,x] xor ((seed + pixel_bias + x_slope*x + y_slope*y) mod 256)`. Then `carry = (carry*carry_mul + sum(stabilized bytes) + carry_add) mod carry_mod` using raw byte sum.

Echo from `/app/archive/echo_segments.jsonl`: choose covering row by greatest `(published_ms, revision, echo_id)`. After stabilizing a full clip, process frames in decreasing `frame_no`. Initial `carry` is `initial_carry` from the selected echo row of the clip's last frame. For each stabilized frame, `tap_sum = sum(stabilized[y,(tap_phase + tap_stride*y) mod 10] for y=0..7)` and `seed = (carry + seed_bias + tap_sum) mod 256`. Pixel `(x,y)` becomes `((stabilized[y,x] + add_mod) mod 256) xor ((seed + x_slope*x + y_slope*y + frame_slope*frame_no) mod 256)`. Then `carry = (carry*carry_mul + sum(stabilized bytes) + sum(echoed bytes at odd row-major indices) + carry_add) mod carry_mod`, with raw sums before the final modulo. Calibration, stabilization, and echo affect final luma, motion, hashes, and contact-sheet pixels, but not later `delta8` predecessors.

Write `/app/output/recovered_timeline.json` as UTF-8 JSON with exact keys. Top level: `cutoff_ms`, `clips`, `archive_sha256`. Each clip, sorted by `clip_id`: `clip_id`, `frame_count`, `first_timestamp_ms`, `last_timestamp_ms`, `motion_total`, `timeline_sha256`, `frames`. Each frame, sorted by `frame_no`: `frame_no`, `timestamp_ms`, `record_id`, `revision`, `published_ms`, `codec`, `luma_sum`, `motion_from_previous`, `sha256`.

`sha256` is lowercase SHA-256 of one final echoed 80-byte frame. `timeline_sha256` is SHA-256 of all final echoed frame bytes for that clip concatenated in frame order. `motion_from_previous` is `0` for the first clip frame, else sum absolute per-pixel luma differences from the previous echoed frame; `motion_total` sums those values. `archive_sha256` is SHA-256 of, for each sorted clip, `clip_id` UTF-8, NUL byte, `timeline_sha256` ASCII, NUL byte, concatenated across clips.

Write `/app/output/contact_sheet.pgm` as binary PGM (`P5`): one row per sorted clip, three 10x8 echoed tiles per row (first, middle `frame_count // 2`, last), one-pixel white separators (`255`) between tile columns and clip rows, no outer border. Final image is 32x26 with header exactly `P5\n32 26\n255\n`, followed by raw pixels.
