Build `/app/replay_lora.py`, a deterministic LoRA replay utility for `/app/data`.

It must run as `python3 /app/replay_lora.py --input-dir INPUT_DIR --output-dir OUTPUT_DIR`. Create `OUTPUT_DIR` if missing. For any input dir with `policy.json`, `base_model.json`, `adapter.json`, and `examples.jsonl`, write exactly `final_adapter.json`, `training_report.json`, `influence_report.json`, and `replay_audit.json` there. Also run it on `/app/data` and leave those four files at `/app/`.

For each `sample_id`, use the current example record with greatest `(effective_tick, revision, ingest_tick)` among records with `effective_tick <= policy.correction_cutoff_tick`; ignore later-effective records. Missing features are zero. Vectors use `policy.feature_order`; class order is `base_model.labels`.

For epoch `e`, start from base `policy.json`, then apply the `policy_revisions` row with greatest `(effective_epoch, revision, ingest_tick)` and `effective_epoch <= e`, if any. Revisions may override `alpha`, `learning_rate`, `adam_lr_decay`, `weight_decay`, `beta1`, `beta2`, `epsilon`, `grad_clip_norm`, `class_weights`, `freeze_B_labels`, and `reset_optimizer_state`. `class_weights` is a sparse overlay on base weights; missing labels get weight `1.0`. `freeze_B_labels` is a replacement list. Missing `adam_lr_decay` means `0.0`. Before each epoch, compare active `freeze_B_labels` with the previous epoch's set (empty before epoch 1); for every label whose membership changed, zero that label's Adam B-row moments. Then, if `reset_optimizer_state` is true, zero all Adam moments and restart the Adam step counter; `optimizer_steps` stays cumulative. Use the final epoch policy for adapter `alpha`/`scale` and holdout metrics.

Train only current `"train"` records; current `"holdout"` records are for metrics only. In every epoch, order train records by `(ingest_tick % policy.order_modulus, sample_id)`. The frozen logit is `base_weight[label] dot x + base_bias[label]`; adapter contribution is `(active_alpha / policy.rank) * B[label] dot (A x)`. Train only `A` and `B`.

Split ordered train records into micro-batches of size `policy.micro_batch_size`. For each batch, compute weighted softmax-cross-entropy gradients scaled by active `class_weights[label]`, averaged over the actual micro-batch length (`len(batch)`, including a short final batch). Accumulate for `policy.grad_accum_steps` micro-batches, or the end-of-epoch tail. On each update, divide by accumulated micro-batch count, zero accumulated B rows for active frozen labels, compute global A/B L2 norm, clip to active `grad_clip_norm` if needed, then apply decoupled AdamW. The effective step LR is `learning_rate / (1 + adam_lr_decay * (adam_step - 1))` using the post-increment Adam bias-correction step counter; both the Adam parameter step and decoupled weight decay must use that same effective LR. Frozen B rows skip Adam moments, weight decay, and parameter updates. A gradients still sum upstream over every label row, including frozen ones.

`final_adapter.json` has exactly `rank`, `alpha`, `scale`, `feature_order`, `labels`, `A`, `B`; `B` aligns to `labels`. `training_report.json` has exactly `selected_train_ids`, `optimizer_steps`, `holdout_loss`, `holdout_accuracy`, `adapter_checksum`, `tail_update_count`, `clip_event_count`, `freeze_scrub_count`; `selected_train_ids` is the ordered current train set. `holdout_loss` is mean active-weighted `-log(p_true)` over current holdout records. `holdout_accuracy` uses greatest logit, earliest label index on ties. `tail_update_count` counts AdamW updates that ended because the epoch ended before a full `grad_accum_steps` accumulation. `clip_event_count` counts updates with `clip_factor < 1.0`. `freeze_scrub_count` totals B-rows zeroed by freeze-membership changes.

`influence_report.json` has exactly `baseline_holdout_loss`, `empty_train_holdout_loss`, `leave_one_out`, `pairwise_label_interactions`, `same_label_pair_skips`, `shapley_values`, `most_helpful_id`, `most_harmful_id`, `influence_checksum`. For each selected ID, retrain from the original adapter with that ID omitted; `leave_one_out` entries, in selected order, contain `sample_id`, `loss_without`, `loss_delta = loss_without - baseline_holdout_loss`, and that run's `adapter_checksum`. Walk upper-triangular selected pairs (`i`, `j > i`): if labels match, count them in `same_label_pair_skips`; if labels differ, retrain with both omitted and append `sample_ids` as `[selected_ids[i], selected_ids[j]]`, `loss_without`, and `interaction_delta = pair_loss_without - baseline_holdout_loss - left_loss_delta - right_loss_delta`. `most_helpful_id` has largest unrounded `loss_delta`; `most_harmful_id` has smallest; ties use lexicographic `sample_id`.

For `shapley_values`, retrain every subset of selected IDs from the original adapter. `empty_train_holdout_loss` is the empty-subset loss. `value(S)` is empty-train loss minus holdout loss after training only on `S`. Emit each ID's exact Shapley value of `value` over all coalitions, in selected order, as `sample_id` plus `loss_shapley`.

`replay_audit.json` covers only the baseline replay and has exactly `selected_records`, `epoch_policies`, `updates`, `audit_checksum`. `selected_records`, in selected order, contain `sample_id`, `label`, `record_key` `[effective_tick, revision, ingest_tick]`, and `order_bucket`. `epoch_policies`, one per epoch, contain `epoch`, `revision_key` or `null`, `reset_optimizer_state`, `alpha`, `learning_rate`, `adam_lr_decay`, `weight_decay`, `beta1`, `beta2`, `epsilon`, `grad_clip_norm`, `class_weights_by_label` in label order after overlays/defaults, and `freeze_B_labels`. `updates`, in chronological order, contain `update_index` (1-based), `epoch`, `adam_step`, `revision_key`, `accumulated_microbatches`, `sample_ids`, `tail_update`, `pre_clip_norm` after frozen-B zeroing and accumulation division but before clipping, and `clip_factor` (`1.0` unless clipped, else `grad_clip_norm / pre_clip_norm`). Compute `audit_checksum` before adding it.

Round every floating output to 12 decimals. Checksums are SHA-256 hex digests of the rounded JSON object with sorted keys and compact separators; `influence_checksum` is computed before adding that field.
