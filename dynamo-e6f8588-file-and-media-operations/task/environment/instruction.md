Recover the approved design master from `/app/data/package` and write `/app/restored_design/final.ppm`, `/app/restored_design/design_report.json`, and `/app/restored_design/recover_design.py`. The Python program must read `PACKAGE_DIR` and `OUTPUT_DIR` environment variables, defaulting to `/app/data/package` and `/app/restored_design`, and produce the same three outputs for any package with this format.

The package manifest is `/app/data/package/package_manifest.json`; the release ledger is `/app/data/package/release_ledger.csv`. Use the manifest `cutoff_utc`. Ledger rows after the cutoff do not exist, and rows whose `timestamp_utc` is exactly equal to `cutoff_utc` are included. Process remaining rows by ascending `timestamp_utc`, preserving file order for equal timestamps. A `release` sets that exact `(asset_id, revision)` released, and a later `revoke` sets it revoked. For each `asset_id`, the active design asset is the highest revision whose final state at the cutoff is released. Layers whose asset has no active revision are skipped.

Every manifest fragment is a payload-only indexed-image rectangle. Validate each fragment against `payload_sha256`. For an `xor_payload_bytes` parity group, if exactly one member is missing or has a bad hash, recover that member by XORing the parity payload with the other member payloads byte by byte; the parity payload itself must match its manifest hash. Decoded fragment rectangles are applied to an initially transparent asset in ascending `sequence`, pixels outside the asset bounds are clipped, and later fragments overwrite earlier pixels.

Untouched asset pixels use the manifest `transparent_index`. Codecs decode to palette-index rows of `width * height` pixels. `idxraw` is raw row-major bytes. `idxrle` stores `(count, palette_index)` byte pairs, expanded in order. `rowdelta` stores the first row raw, then each later byte is XORed with the decoded byte directly above it.

Render manifest `layers` in file order onto an RGB canvas initialized to the manifest background palette color. Palette entries are `[red, green, blue, alpha]`; palette alpha 0 pixels do not draw. For each in-bounds source pixel, compute `alpha = floor(palette_alpha * opacity_num / opacity_den)` and source-over blend each RGB channel as `floor((src * alpha + dst * (255 - alpha) + 127) / 255)`. Coordinates are zero-based; negative layer offsets clip normally.

`/app/restored_design/final.ppm` must be ASCII P3: header `P3`, then `width height`, then `255`, then one row of space-separated RGB integers per canvas row, ending with a single trailing newline after the last row. `/app/restored_design/design_report.json` must be a minified JSON object with sorted keys, followed by a single trailing newline, and exactly `cutoff_utc`, `canvas`, `active_assets`, `layers`, and `ppm_rgb_sha256`. `canvas` has `width` and `height`. `active_assets` is sorted by `asset_id`; each entry has `asset_id`, `revision`, and `pixel_sha256`, the SHA-256 of the active asset's palette-index bytes after fragment repair. `layers` lists drawn layers in render order; each entry has `layer_id`, `asset_id`, `revision`, `x`, `y`, and `drawn_pixels`, counting source pixels with computed alpha greater than zero that land in bounds. `ppm_rgb_sha256` is the SHA-256 of the final canvas RGB bytes in row-major order, not the PPM text.

All three outputs must be regular files.
