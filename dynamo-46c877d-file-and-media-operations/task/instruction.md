Each object must contain exactly these keys and no others: `out`, `source`, `frame`, `packet_id`, and `revision`. `out` is the zero-based output frame index; the remaining fields identify the selected packet used for that frame. For freeze slots, every repeated output position still reports the `start_tc` source frame number.
