Create an executable Python 3 program at `/app/rebuild_atlas.py`. It must accept one argument, a workspace directory, and rebuild that workspace's design atlas. Also run it once on `/app/studio_case`.

Each workspace contains `layout.json`, `manifest.jsonl`, and a `fragments/` directory. `layout.json` has integer `cell_size`, `columns`, `rows`, `gutter_px`, and `cutoff_tick`. The output atlas is RGBA PNG, with width `columns * cell_size + (columns - 1) * gutter_px` and matching height for rows. Gutter pixels are fully transparent.

Each nonblank line of `manifest.jsonl` is a JSON object. Records have `record_id`, `slot`, `revision`, `effective_tick`, `action`, `fragment`, `transform`, and `listed_sha256`. `slot` is `[x, y]` with zero-based cell coordinates. Valid actions are `paint` and `erase`. Valid transforms are `identity`, `rot90`, `rot180`, `rot270`, `flip_x`, and `flip_y`; rotations are clockwise. `flip_x` mirrors left-to-right across the fragment's vertical centerline, and `flip_y` mirrors top-to-bottom across the fragment's horizontal centerline.

After JSON parses successfully, if `effective_tick` is an integer greater than `cutoff_tick`, discard the record as `future_records_ignored` immediately — even when other fields are also invalid — and do not count it in `ignored_records` or `ignored_by_reason`. Only after that future check, ignore a remaining record if the JSON is malformed, required fields have the wrong type, the slot is outside the layout, the action or transform is unknown, a `paint` fragment is missing, or a `paint` record's digest is wrong. Required numeric fields (`slot` coordinates, `revision`, and `effective_tick`) must be JSON numbers whose values are integers; JSON strings and booleans count as the wrong type. A `paint` fragment path must be relative and must resolve inside the workspace's `fragments/` directory; absolute paths and paths that escape `fragments/` count as missing.

Fragments are 8-bit PNGs, sequential or Adam7-interlaced, with color type 0 (grayscale), 2 (RGB), 3 (indexed with `PLTE` and optional `tRNS`), or 6 (RGBA). Decode to raw row-major RGBA before any digest or transform: grayscale becomes `(g,g,g,255)`, RGB becomes `(r,g,b,255)`, indexed samples `PLTE`/`tRNS`, and RGBA is unchanged. The digest is SHA-256 of those decoded RGBA bytes before applying the transform, not the PNG file bytes. After transformation, a painted fragment must be exactly `cell_size` by `cell_size`; otherwise ignore it. `erase` records do not use a fragment or digest.

For each slot, choose the last valid record after sorting that slot's valid records by `effective_tick`, then `revision`, then `record_id`, all ascending. If the winning record is `erase`, leave that slot fully transparent. If it is `paint`, copy the transformed RGBA pixels into the slot. Slots with no valid record are transparent.

For the requested workspace, create regular files under `<workspace>/restored/`: `atlas.png` and `report.json`. Do not create symlinks. After both files are written, delete every file under `<workspace>/fragments/` (keep the empty directory; do not delete `layout.json` or `manifest.jsonl`).

The report must be JSON with exactly these keys: `accepted_paints`, `accepted_erases`, `ignored_records`, `ignored_by_reason`, `future_records_ignored`, `superseded_valid_records`, `shadowed_fragments`, `painted_slots`, `erased_slots`, `transparent_slots`, `winning_records`, and `atlas_sha256`.

`accepted_paints` and `accepted_erases` count all valid input records before winner selection. `ignored_records` counts every ignored non-future manifest line. `ignored_by_reason` is an object with exactly these integer keys: `malformed_json`, `bad_schema`, `bad_slot`, `bad_action_or_transform`, `missing_fragment`, `digest_mismatch`, and `wrong_transformed_size`. Count malformed JSON lines as `malformed_json`; missing required fields or wrong field types as `bad_schema`; out-of-layout slots as `bad_slot`; unknown actions or transforms as `bad_action_or_transform`; missing, unreadable, absolute, or escaping paint fragment paths as `missing_fragment`; digest mismatches as `digest_mismatch`; and valid decoded fragments whose transformed dimensions are not `cell_size` by `cell_size` as `wrong_transformed_size`. `superseded_valid_records` counts valid records that did not win their slot. `shadowed_fragments` counts distinct `fragment` path strings that appear on at least one accepted paint (a record counted in `accepted_paints`) and do not appear on any winning paint record; paints rejected for digest mismatch, missing fragments, or wrong transformed size do not contribute. `painted_slots` and `erased_slots` count final winning slot states. `transparent_slots` counts erased plus never-painted final slots. `winning_records` is an array sorted row-major by slot, including only slots that had a valid winning record; each item is `{"slot":"x,y","record_id":"...","action":"paint|erase"}`. `atlas_sha256` is the SHA-256 of the output atlas's decoded raw RGBA bytes.
