Create executable Python 3 `/app/rebuild_mix.py`. It accepts exactly one session directory. For `/app/data/session-visible`, write `/app/data/session-visible/restored/restored_mix.wav` and `/app/data/session-visible/restored/restored_manifest.json`; other sessions use their own `restored/`. Then empty `clips/` recursively, preserving that directory and non-`clips/` files. Run it once on `/app/data/session-visible`.

A session contains `manifest.json`, `events.tsv`, `assets.tsv`, and `clips/`. `manifest.json` has `case_id`, `tracks`, `blocks`, `block_samples`, `cutoff`, `pad_sample`. Render `blocks * block_samples` stereo frames at 44100 Hz from `(pad_sample,pad_sample)`. Output WAV is mono 16-bit PCM after downmix.

`events.tsv`: `event_id`, `slot_id`, `track`, `block`, `layer`, `asset_id`, `version`, `known_at`, `action`, `path`, `transform`, `gain`, `source_hint`. Ignore `path` and `source_hint`; resolve clips through `assets.tsv`. Count and ignore `known_at > cutoff`. Count but do not select `void`. For each `(slot_id, layer)`, choose the non-void event with greatest numeric/lexicographic `(known_at, version, event_id)`. Chosen `delete` is absent; chosen `place` renders.

Optional sidecars are later-row-wins by `(slot_id, layer)`: `gains.tsv` gain override; `mix_modes.tsv` mode `over`/`under`, default `over`; `offsets.tsv` `dx`,`dy`, default `(0,0)`; `envelopes.tsv` `.env` path; `splices.tsv` `.spl` path; `feedback.tsv` `tap_dx`, `amount`, mode `feed`/`duck`.

Clips are mono/stereo 16-bit PCM `.wav`, or mono `.dpcm`. DPCM is `DPCM1 <n>`, first sample, then `delta count` rows; reconstruct cumulative clipped int16 deltas. Clip and `.env` lengths are `block_samples`; expand mono to stereo `(s,s)`. `.env` is `ENV1 <n>` plus `gain count` RLE rows. Frame `i` uses transformed-clip `env_gain[i]`; clipped-away frames do not reindex. Effective gain is `trunc_toward_zero(base_gain * env_gain[i] / 255)`, or base gain without `.env`; transforms never reorder envelope gains.

Apply `transform` left to right: `none`, or `|`-separated `reverse`, `invert`, `swaplr`. `reverse` reverses frames; `invert` uses `clip16(-s)` per channel; `swaplr` swaps channels and still counts on mono. Remap offsets by inverse ops right to left: `reverse`: `dx = block_samples - 1 - dx`; `invert`: no-op; `swaplr`: swap `dx,dy`. Place at `block * block_samples + remapped_dx`; `dy` only matters if swapped into `dx`. Clip to bus bounds.

`.spl` is `SPLICE1 <n>` (`n=block_samples`) then `start count dst_shift gain_delta polarity channel`. Rows address transformed-clip indices; later rows win; defaults are `0 0 keep both`. Frame `i` uses splice index `i`: `flip` applies `clip16(-s)` to both channels; `keep` leaves them. Channel is `both`, `left` `(left,0)`, `right` `(0,right)`, or `swap` `(right,left)`. Adjusted gain is `clamp0_255(eff_gain + gain_delta)`. Destination: `block * block_samples + remapped_dx + i + dst_shift`.

If feedback is assigned, each in-bounds destination frame reads current bus frame `destination + tap_dx` immediately before compositing; frame indices ascend, so earlier frames can affect later taps. `feed` sets source to `clip16(src + trunc_toward_zero(tap * amount / 255))`; `duck` subtracts it. Feedback changes `src_unscaled`; gain and destination do not change.

Render sorted by `(layer, mode_rank, known_at, slot_id)`, with `under=0`, `over=1`. Composite channels with integer math and `clip16`. `over`: `clip16(dst + trunc_toward_zero(src * eff_gain / 255))`. `under`: `clip16(trunc_toward_zero(dst * (255 - eff_gain) / 255) + src_unscaled)`, where `src_unscaled` is transformed, spliced, feedback-adjusted source before gain scaling. Downmix to mono with `clip16(trunc_toward_zero(left + right, 2))`. Use no floats.

`restored_manifest.json` contains only: `case_id`, `mix_sha256`, `total_slots`, `visible_events`, `future_events_ignored`, `void_events_ignored`, `superseded_events`, `selected_events`, `placed_layers`, `deleted_layers`, `wav_sources`, `dpcm_sources`, `transform_ops`, `gain_scaled_layers`, `gain_overrides`, `offset_layers`, `enveloped_layers`, `spliced_layers`, `splice_shifted_frames`, `splice_gain_delta_frames`, `splice_channel_frames`, `feedback_layers`, `feedback_tapped_frames`, `feedback_changed_frames`, `under_mixes`, `occupied_slots`, `stacked_cells`, `empty_slots`. `mix_sha256` is SHA-256 of exact WAV bytes. `total_slots = tracks * blocks`; `visible_events` counts `known_at <= cutoff`; `superseded_events` counts visible non-void events not chosen; `selected_events = placed_layers + deleted_layers`. Source counts use resolved extension. `transform_ops` counts atomic non-`none` ops on placed events. `gain_scaled_layers` counts placed layers whose base gain after any `gains.tsv` override, before envelope, is not 255. Count gain overrides, enveloped, spliced, feedback, and under layers; occupied `(track,block)` cells; stacked cells with at least 2 placed events; `empty_slots = total_slots - occupied_slots`. `offset_layers` counts placed layers whose full remapped `(dx,dy)` is not `(0,0)`, including `dy`. Splice frame counters count transformed clip indices before bus clipping after file-row overrides: nonzero `dst_shift`, nonzero `gain_delta`, and `channel != both`. Feedback counters count in-bounds destination frames with in-bounds taps, and those whose source pair changed.
