# Recover Design Sheet

This Harbor task asks the agent to build a reusable `/app/restore_design.py` program and use it to reconstruct `/app/recovered_sheet.ppm` plus `/app/recovery_report.json` from the public job bundle in `/app/design_job`.

The input is a synthetic prepress recovery bundle made of indexed PGM fragments, mask rasters, parity repair shards, registration markers, palette revision metadata, palette aliases, source windows, scan-order metadata, orientation metadata, layer ordering, and erase/over blend modes. The intended difficulty is preserving the coupled image semantics: both text `P2` and binary `P5` PGM encodings must parse correctly, `repair:<id>` rasters must be reconstructed by bitwise-XORing their declared shards before scan normalization or orientation, `254` registration markers derive placement after the raster transforms and are not painted, masks may have their own storage scan/orientation metadata, source windows crop transformed rasters before placement, serpentine rows must be normalized before orientation, fragments must be composited in `(z, captured_at, id)` order, palette revisions and aliases are selected at capture time, erase fragments restore the declared background, and masked opacity must be composited in linear-light sRGB rather than directly in 8-bit sRGB.

Verification parses the requested visible PPM/report and recomputes expected results from the public manifest. It also runs the submitted reusable script on verifier-generated jobs that exercise point-in-time palette selection, palette aliases, source windows, relative and absolute fragment paths, clipping, flips, rotations, serpentine scan order, binary P5 rasters and masks, independent mask scan/orientation, erase behavior, registration-derived placement after source-window cropping, parity repair groups for both fragments and masks, mask coverage, opacity, linear-light compositing, inverse masks, `atop-background` state dependence, and a compound fixture that couples those branches in one job.
