Each manifest fragment is a payload-only packet. Validate every packet against its `payload_sha256`. For an `xor_payload_bytes` parity group, if exactly one member is missing or has a bad hash, recover that member by XORing the parity payload with the other member payloads byte by byte; the parity payload itself must match its manifest hash. For a `gf256_linear_payloads` parity group, `members` lists equal-length payload path strings and each `parity_rows` entry has `path`, `payload_sha256`, and `coefficients`; `path` is the parity payload file, `payload_sha256` validates that parity payload, and `coefficients` is in the same order as `members` with one coefficient per member. The field is GF(256) with reduction polynomial `0x11b`; byte addition is XOR, and multiplication is carryless multiplication modulo `0x11b`. If `k` members are missing or bad, scan `parity_rows` in manifest order and use the first `k` rows whose coefficients for the missing members form a nonsingular `k x k` matrix; parity rows may be dependent or redundant. Recover the missing member bytes by solving that system over GF(256) independently at every byte offset, then validate the recovered payload hashes.

Decode fragment codecs into signed 16-bit PCM frames, then concatenate fragments for each active asset by ascending `sequence`. `PCM16` is little-endian interleaved samples. `DLT16` stores little-endian signed deltas per channel; the first frame is absolute and later frames add the delta to the previous sample in the same channel. `BDL16` is also little-endian signed deltas per channel, but it resets at fixed-size frame blocks: the manifest field `block_size` gives the block length, the first frame of each block is absolute, and later frames add the delta to the previous sample in the same channel within that block. `MS16` stores stereo little-endian `(mid, side)` pairs, where `mid = floor((left + right) / 2)` and `side = left - right`; recover `left = mid + ceil(side / 2)` and `right = left - side`. `PRD16` stores signed residuals, not samples: the payload is channel-major, with all residuals for channel 0, then channel 1, and so on. For frame `n` and channel `c`, compute `predicted = trunc_toward_zero(sum(predictor_taps[i] * prior_i) / predictor_den)`, where `prior_i` is the already decoded sample at frame `n - i - 1` in the same channel when that frame is nonnegative, otherwise `warmup_samples[c][i - n]`. The decoded sample is `residual + predicted`.
